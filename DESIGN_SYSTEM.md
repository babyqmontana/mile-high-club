# DESIGN SYSTEM — Mile High Club «Vertical Noir»

> Этап 4 из MASTER TASK. Документ описывает **эволюцию** существующей визуальной системы (`public/css/app.css`), а не замену.
> Палитра, шрифты и предметные метафоры, которые уже есть в проекте, сохраняются. Новое добавляется поверх существующих токенов.

---

## 1. Идея

**Отель — вертикаль.** Mile High Club — сорок этажей над Лос-Сантосом. Сейчас сайт навигационно «плоский»: восемь равноправных разделов, у всех одинаковые шапка, заголовок, карточки и анимация появления.

Принцип системы: **каждая страница — этаж со своим материалом и светом**, а переход между страницами — **поездка на лифте**. Это даёт:

* единую логику переходов (вверх или вниз по реальным этажам площадок из данных `venue.floor`);
* индивидуальность каждой страницы через **материал**, а не через новые случайные компоненты;
* смысловую опору для 3D: башня, хьюмидор и атриум — это «окна» на этажи, а не декор.

| Страница | Этаж (из данных или README) | Материал | Свет | Характер композиции |
|---|---|---|---|---|
| Главная / атриум | Атриум | латунь + бархат | тёплый неон, вечерний | кинематографичная, вертикальный сюжет |
| Номера | 20–26 | стекло фасада, ключ-карта | холодный небесный → золотые окна | инструмент: 3D + панель |
| Отдых | 38 / 40 | вода, солнце, винил | день: белое солнце; ночь: маджента | ритм, шкала времени |
| Le Ciel | 30 | лён, серебро, фарфор | мягкий верхний | меню-карта, много воздуха, serif |
| Сигарный клуб | 31 | кожа, кедр, дым | низкий янтарный | тёмная витрина, один объект в фокусе |
| Журнал | — | бумага, типографика | нейтральный дневной | редакционная, асимметричная сетка |
| Персонал | — | ткань униформы | студийный | портреты, униформа как каталог |

| Панель персонала | служебный | бумага-бланк | ровный | плотная, утилитарная, **без** декоративной анимации |

### 2.2 Новые семантические токены (добавляются, старые не удаляются)

```css
:root{
  /* поверхности по «высоте» — глубина светом, а не тенью */
  --surface-0: var(--bg);           /* пол */
  --surface-1: var(--bg2);          /* утопленные поля, дорожки */
  --surface-2: var(--card);         /* панели */
  --surface-3: var(--card2);        /* поднятые/активные */
  --edge: var(--line);              /* 8% крема */
  --edge-strong: var(--line2);      /* 17% крема */
  --edge-brass: linear-gradient(90deg,#8a6228,#f9edc7 50%,#8a6228); /* только для ар-деко рамок и циферблатов */

  /* статусы — единые для номеров, площадок, заказов, тикетов */
  --st-free: var(--gold);  --st-booked: var(--pink);  --st-occupied: var(--violet);
  --st-idle: var(--mut);   --st-live: var(--pink);    --st-ok: var(--ok);  --st-bad: var(--bad);

  /* материал этажа: каждая страница переопределяет 3 переменные */
  --floor-tint: var(--wine);        /* цвет «света этажа» в фоне */
  --floor-accent: var(--gold);      /* главный акцент страницы */
  --floor-grain: .04;               /* непрозрачность фактуры */
}
.view[data-view="leisure"]{--floor-tint:#3a1a2a;--floor-accent:var(--pink)}
.view[data-view="dining"] {--floor-tint:#2a2320;--floor-accent:#E9E4DA}
.view[data-view="cigars"] {--floor-tint:#2a160c;--floor-accent:#C9A24A}
.view[data-view="journal"]{--floor-tint:#221c18;--floor-accent:var(--fg)}
.view[data-view="contact"]{--floor-tint:#241a12;--floor-accent:var(--gold)}
```

### 2.3 Правила
* **Один главный акцент на экран.** Маджента = действие (CTA, «Live»). Золото = доступность и ценность (свободно, цена, латунь). Оранж = занятость или предупреждение. Крем = текст.
* Фиолетово-синих градиентов нет. Холодный цвет допускается **только** в небе 3D-сцен (день) и в воде бассейна.
* **Градиенты — только физические:** отражение на металле (латунь, серебро клоша), свет неона, закат над городом. Градиент-подложка под текст — нет.
* `--sunset` — только индикатор прокрутки и подчёркивание активного пункта меню, статично. `.eyebrow` — цвет этажа `--floor-accent` с короткой чертой слева, без анимации (аудит, P6). **Сделано на этапе A.**
* Контраст: `--mut` на `--card` = 7,4:1, `--fg` на `--bg` = 16:1; маджента на тёмном только для крупного текста и иконок (4,6:1).

## 3. Типографика

Шрифты сохраняются. Меняется **роль и загрузка**.

| Роль | Шрифт | Где | Правило |
|---|---|---|---|
| Display | Unbounded 600–800 | H1/H2, номера этажей и комнат | `letter-spacing:-.025em`; цифры — `tabular-nums`; не длиннее 3 строк |
| Body | Onest 400–700 | текст, интерфейс | 16 px базовый, 1.6 |
| Accent serif | Cormorant Garamond italic | одна фраза в заголовке, меню Le Ciel, цитаты | не больше одной serif-вставки на заголовок |
| Utility caps | Onest 800, `.2em`, uppercase | eyebrow, лейблы, статусы | без анимации |
| Table / mono-like | Onest + `tabular-nums` | время, цены, коды брони | — |

**Шкала (fluid, clamp):**
```
--t-hero:    clamp(2.4rem, 5.6vw, 5.2rem)   /* только атриум */
--t-h1:      clamp(2rem, 5vw, 3.6rem)        /* = текущий .head h2 */
--t-h2:      clamp(1.4rem, 3vw, 2.2rem)
--t-h3:      1.3rem
--t-body:    1rem
--t-small:   .84rem
--t-caps:    .68rem
```

**Загрузка:** было 14 начертаний, оставлено 10 — ровно те, что используются в CSS: Unbounded 600/700/800, Onest 400/600/700/800, Cormorant Garamond 500i/600i/700 (700 — для заголовков журнала с `font-weight:900`). `display=swap`. Preload файлов Google Fonts не делаем: их URL меняются. Неразрывные фразы в заголовках: `Лос‑Сантос` через неразрывный дефис (U+2011) в шаблоне, чтобы не было переноса «Лос-/Сантосом».

**Kinetic type (только 3 места):** H1 атриума (построчное раскрытие маской), цифры на табло «свободно» (split-flap), номер этажа в HUD лифта (прокрутка цифр как в механическом указателе). Больше нигде.

## 4. Размеры, сетка, отступы

* Контейнер `.wrap` 80rem — без изменений.
* **Сетка 12 колонок** с `gap: clamp(.75rem, 2vw, 1.5rem)` для главной и журнала. Остальные страницы используют свою раскладку (см. §1).
* Отступы — шкала 4 px: `--s1:.25rem --s2:.5rem --s3:.75rem --s4:1rem --s5:1.5rem --s6:2rem --s7:3rem --s8:5rem --s9:8rem`.
* Вертикальный ритм секций — `.sec` (`clamp(2.5rem,6vw,5rem)`) сохраняется; на главной между «этажами» — `--s9`.
* **Асимметрия обязательна** хотя бы в одном блоке каждой страницы: например, заголовок на 5 колонках и контент на 7 со смещением, а не центрированный стек.

## 5. Радиусы

| Токен | Значение | Применение |
|---|---|---|
| `--r` | 1.25rem | крупные панели, сцены 3D (как сейчас) |
| `--r2` | .875rem | поля, мелкие карточки (как сейчас) |
| `--r-pill` | 999px | кнопки, чипы, сегменты |
| `--r-deco` | 0 + срез угла 10px (`clip-path`) | **новый**: ар-деко элементы — ключ-карта, бирки цены, табло |

Правило: на одной странице не больше двух радиусов, кроме таблеток.

## 6. Глубина, тени, свет

* Тени не используются для «подъёма» карточек. Глубина = **поверхность выше → светлее на 1 ступень** (`--surface-*`) + **верхний блик 1px** `inset 0 1px 0 rgba(249,237,199,.06)`.
* Единственная выраженная тень — у плавающих элементов (FAB, sheet, модалка): `--shadow` (уже есть).
* **Свет этажа:** у каждой страницы фоновое пятно `radial-gradient` цвета `--floor-tint` сверху слева — заменяет текущее общее `body::after`. Меняется плавно при смене страницы (переход «лифт приехал на этаж»).
* **Зерно:** SVG-шум (`feTurbulence`, data-URI, ~0,4 КБ) с непрозрачностью `--floor-grain` поверх фона — даёт фактуру бархата/бумаги без картинок.
* **Никаких стеклянных карточек** (`backdrop-filter`). Исключение — шапка при прокрутке поверх атриума, и то как сплошной `--glass`, как сейчас.

## 7. Анимация

### 7.1 Токены
```css
:root{
  --ease-out:    cubic-bezier(.2,.8,.2,1);    /* уже используется в проекте — основной */
  --ease-in-out: cubic-bezier(.65,0,.35,1);   /* двери лифта, смена страниц */
  --ease-spring: cubic-bezier(.2,.9,.3,1.3);  /* уже есть у FAB — только для «щелчков» */
  --d-tap:   120ms;   /* нажатие */
  --d-hover: 200ms;   /* наведение */
  --d-ui:    320ms;   /* открытие меню, чипы */
  --d-panel: 480ms;   /* sheet, модалка */
  --d-floor: 720ms;   /* переход между страницами = текущий таймер лифта goFloor() */
  --d-scene: 1200ms;  /* камера 3D */
}
```

### 7.2 Правила
1. **Анимация объясняет причину и следствие.** Добавил блюдо → оно летит в FAB. Подтвердили бронь → окно номера на башне меняет цвет. Сменился этаж → двери.
2. **Появление при прокрутке — максимум одно на секцию**, и разное по смыслу: табло «перещёлкивается», расписание «заполняется» слева направо до текущего часа, журнал «раскрывается» как разворот. Универсальный `.reveal` (снизу вверх) остаётся только как fallback.
3. **Бесконечные анимации** только у «живых» индикаторов (точка Live, пульс «Свободно») и только пока элемент виден.
4. Только `transform`, `opacity`, `clip-path`, `filter: blur` (короткий). Никаких анимаций `width`/`height`/`top`.
5. **`prefers-reduced-motion`:** переходы страниц становятся crossfade 150 мс; WebGL-сцены рендерят один кадр и обновляются только по событию; параллакс и курсорные эффекты отключаются. Глобальное правило в `app.css` сохраняется.
6. Одновременно на экране не больше **одного** WebGL-цикла `requestAnimationFrame` и **одного** 2D-канваса погоды.

### 7.3 Переход между страницами («лифт»)
* Направление = сравнение «этажей» маршрутов (атриум 0 → номера 20 → Le Ciel 30 → клуб 31 → бассейны 38/40). Поднимаемся → контент уезжает вниз, новый приходит сверху. И наоборот.
* Реализация: **View Transitions API** (`document.startViewTransition`) для same-document — у нас SPA, поэтому достаточно same-document версии (Chromium, Safari 18+, Firefox 144+). Где API нет — текущая CSS-анимация `vin`.
* Во время перехода в шапке крутится номер этажа (HUD-цифры), звучит существующий `play('whoosh')`/`ding`.
* Длительность `--d-floor`; ввод не блокируется.

## 8. Интерактивность — правила

1. **Всё, что выглядит кликабельным, — кликабельно и что-то меняет в данных или виде.** Плитки, которые сейчас ведут ссылкой «куда-то» (например, плитка площадки → `#leisure`), ведут к конкретному элементу (`#leisure` + прокрутка к карточке площадки).
2. **Курсор:** кастомный курсор не вводим глобально (это снижает доступность и спорно для форм). Вводим **контекстные курсоры** только на интерактивных сценах: «тянуть» над башней и хьюмидором, «листать» над журналом, «скрэтч» над пластинкой — через CSS `cursor: url(svg)` + текстовая подсказка, без JS-follower.
3. **Магнитные кнопки:** только главная CTA атриума и FAB корзины, амплитуда ≤ 6 px, только `pointer: fine`.
4. **Hover на тач-устройствах** не несёт информации, которой нет без hover (например, подсветка номера на фасаде дублируется выбором).
5. Каждый 3D-объект имеет **DOM-альтернативу** с тем же действием (кнопки лифта ↔ этажи башни, лента ↔ сигары хьюмидора) — уже так, сохраняем и связываем `aria-controls`.
6. Звуки — только в ответ на действие пользователя; уважают `soundOn`.

## 11. Адаптивность

| Брейкпоинт | Правило |
|---|---|
| ≤ 420 | погода прячется в drawer; в шапке 3 иконки максимум: свободно, профиль, меню |
| ≤ 640 | sheet → bottom sheet; табло в 1 колонку; лента пакетов — горизонтальный scroll-snap |
| ≤ 980 | 3D-сцены над панелями, высота `min(70svh, 34rem)`; лифт — горизонтальная лента этажей (уже так) с автопрокруткой к выбранному |
| ≥ 1800 | существующее масштабирование `html{font-size}` сохраняется |
| touch | нет hover-зависимостей; все жесты имеют кнопку-дубль; цели ≥ 44×44 px |
| `svh/dvh` | использовать `svh` для полноэкранных блоков (iOS адресная строка) |
