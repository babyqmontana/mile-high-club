# Mile High Club — дизайн-система (ветка redesign)

Подобрана по UI UX Pro Max и адаптирована под бренд отеля. Предложения скилла по синей палитре и новым шрифтам не приняты: бренд винно-красный с кремом, шрифты по решению владельца не меняются.

## Стиль
Тёмный журнальный люкс: Exaggerated Minimalism + Editorial Grid + Dark Mode (OLED).
- Крупная типографика, много воздуха, один акцент.
- Свечение только у статусов и акцента, без декоративного шума.

## Цвет
| Роль | Значение |
|---|---|
| Фон | `#0A0607`, поверхности `#120A0C` / `#170D10` / `#211317` |
| Текст | `#F6EBD6` (17:1), второстепенный `#BFB2A0` (9,7:1) |
| Акцент действий | шампанское золото `#E9B44C`, текст на нём `#1A0F05` (10:1) |
| Статусы и счётчики | красный логотипа `#D23A48` |

Розовый и оранжевый не используются для кнопок.

## Типографика
Unbounded (заголовки), Onest (текст), Cormorant Garamond курсив (акценты и цитаты).
- Заголовок раздела: `clamp(2.4rem, 6.2vw, 5rem)`, межстрочный 0.98, трекинг −0.02em, `text-wrap: balance`.
- Текст 16 px, межстрочный 1.65, абзацы до 60 знаков.

## Ритм и состояния
- Отступы разделов `clamp(4rem, 9vw, 8rem)`.
- Сенсорные цели не меньше 44 px; фокус — золотая обводка 2 px с отступом 3 px.
- Переходы 180–260 мс, при «уменьшить движение» отключаются.
- Пустое состояние: иконка, что это, почему пусто.
- Скрытые элементы (корзина, панель брони) недоступны с клавиатуры.

## Паттерн главной
Атриум → табло → афиша → пакеты → отзывы → этажи → призыв «Ваш номер над городом уже ждёт» → Discord.
На телефоне после первого экрана — закреплённая панель брони (кроме «Номеров», «Заявки», кабинета и корзины).
