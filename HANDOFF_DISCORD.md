# Передача задачи: Discord-интеграция и новый логотип

Этот файл нужен, чтобы продолжить работу в сессии на ПК. Облачная сессия до компьютера не дотягивается.

## Задача (слова владельца проекта)

- Полная интеграция сайта с Discord-сервером **MHC**: айдентика, роли, каналы, разграничение ролей и доступа к веткам, эмбеды и прочее.
- Боты и их активности со своими аватарками в стиле отеля.
- Заменить логотип на новый (`brand/logo-source.webp`, верблюд с трубкой, «MILE HIGH CLUB»). Логотип должен быть квадратным, чтобы вставлять его в миниатюры.
- Проект внутриигровой, для full RP (GTA, Лос‑Сантос): тексты от лица отеля (IC), правила сервера отдельно (OOC).
- Работать в desktop‑приложении Discord, на сервере MHC. Владелец залогинен в Discord Developer Portal и Supabase в браузере.
- Изначальная задумка сайта описана владельцем в другом чате. Если нужны детали, попросить его вставить текст.

## Что уже есть в коде

`server/bot.js`:
- `LAYOUT` с тремя ролями, категориями и каналами;
- `hooks.setupGuild` (идемпотентный, создаёт только недостающее);
- уведомления о бронях, заказах и тикетах;
- канал-тикет;
- счётчик свободных номеров;
- синхронизация событий;
- `resolveRole` для входа на сайт (guest / mod / admin).

Маршруты в `public/js/core.js`:
- `POST /admin/discord/setup`;
- `POST /admin/discord/post`.

## План

1. **Логотип.** Цвета: кремовый `#F6E8D2`, бордовый `#7A1E26`, чёрный `#080405`.
   - Векторизовать: `pip install vtracer` → снап к палитре → трассировка → силуэт‑подложка, чтобы внутренние чёрные линии оставались на любом фоне.
   - Экспортировать:
     - полный логотип в квадрате (`public/img/logo.webp`, сейчас квадрат 640×640, используется в `main.js` и `index.html`);
     - эмблему, то есть верблюда в бордовом круге (шапка сайта 42px, ключ‑карта, аватар бота, иконка сервера);
     - favicon.
2. **Схема сервера** (декларативно, вынести из `bot.js` в `server/discord/layout.js`):
   - **Роли руководства и персонала:** Владелец, Управляющий, Зам. управляющего, Руководитель отдела, Сотрудник, Стажёр.
   - **Роли отделов:** их 8 в `depts`, цвета из сида.
   - **Роли гостей:** Гость отеля (после принятия правил), Постоялец (бот выдаёт при заселении и снимает при выезде), Член сигарного клуба, Пресса.
   - **Роли‑подписки:** анонсы, вечеринки, сигары, Le Ciel, журнал.
   - **Категории и каналы:**
     - ЛОББИ (видно всем): добро‑пожаловать с кнопкой входа, правила, о‑отеле, роли;
     - ОТЕЛЬ (живые эмбеды из базы): номера, площадки, меню, сигары, предложения, афиша, журнал, персонал, faq;
     - ГОСТИНАЯ, включая голосовые;
     - ПОСТОЯЛЬЦЫ;
     - СИГАРНЫЙ КЛУБ;
     - ОБРАЩЕНИЯ: тикет и трудоустройство, через модалки;
     - СЛУЖЕБНОЕ (сюда переходят текущие брони, заказы и обращения);
     - ОТДЕЛЫ;
     - РУКОВОДСТВО (журнал действий);
     - РЕДАКЦИЯ;
     - ТИКЕТЫ.
   - Существующие ключи каналов и ролей (`main`, `rooms`, `staffBookings`, `catTickets`…) сохранить. Ничего не удалять.
3. **Сухой прогон.** `planSetup(blueprint, snapshot)` — чистая функция, тестируется без Discord. В панели показывается предпросмотр перед развёртыванием.
4. **Персоны.** Через вебхуки с аватарками отделов: Консьерж, Ресепшен, Le Ciel, The Hot Times, Бассейны, Сигарный клуб, Журнал, Охрана, Управляющий. Отдельные боты возможны только через приложения, созданные владельцем в Developer Portal.
5. **Активность бота.** Ротация статуса: свободные номера, что сейчас открыто, подсказка по `/`-командам.
6. **Слэш‑команды:**
   - для гостей: `/номера`, `/площадки`, `/меню`, `/афиша`, `/бронь` (модалка → `core.handle('POST','/bookings')`), `/мои-брони`, `/обращение`;
   - для персонала: `/подтвердить`, `/заселить`, `/выселить` (через `/admin/bookings/:id/action`), `/смена`.
7. **Иконка и аватар.** Иконка сервера и аватар бота из эмблемы, по флагу в панели.
8. **Проверка.** Тесты на имитации гильдии: повторный запуск ничего не создаёт; @everyone не видит служебное; гость не видит отделы.
   - Затем живой прогон на сервере MHC.
   - Для бота нужны права Manage Roles, Manage Channels, Manage Webhooks, Manage Guild (иконка), Manage Events и Server Members Intent.

## Нужно от владельца

- `DISCORD_BOT_TOKEN`, `GUILD_ID` (сервер MHC), `DISCORD_CLIENT_ID`/`SECRET` в `.env`. В git не коммитить.
- Нужен ли переезд базы на Supabase: сейчас SQLite. Это архитектурное решение, только с согласия владельца.
