# Запуск бота на сервере MHC

Код бота готов и покрыт тестами на имитации (`npm run test:discord`). На живом сервере он ещё не запускался: для этого нужны токен и ID сервера.

## 1. Создать приложение

1. Откройте [Developer Portal](https://discord.com/developers/applications) → New Application → имя `Mile High Club`.
2. Вкладка **Bot**: Reset Token, скопируйте токен. Включите **Server Members Intent**.
3. Вкладка **OAuth2**: скопируйте Client ID и Client Secret. В Redirects добавьте адрес из `DISCORD_REDIRECT_URI`.

## 2. Пригласить бота

Подставьте Client ID и откройте ссылку:

```
https://discord.com/oauth2/authorize?client_id=CLIENT_ID&scope=bot%20applications.commands&permissions=387355627120
```

В этом числе только нужные права: просмотр и сообщения, ветки, голос, управление ролями, каналами, вебхуками, сервером и событиями.

После приглашения в **Настройках сервера → Роли** перетащите роль бота выше всех ролей MHC. Иначе бот не сможет их выдавать.

## 3. Заполнить `.env`

Скопируйте `.env.example` в `.env` и заполните `DISCORD_BOT_TOKEN`, `GUILD_ID`, `DISCORD_CLIENT_ID`, `DISCORD_CLIENT_SECRET`, `PUBLIC_URL`. ID сервера: включите режим разработчика в Discord, затем правый клик по серверу → Копировать ID. Файл `.env` в git не попадает.

## 4. Развернуть

```bash
npm start
```

Войдите в панель сайта как администратор, откройте раздел **Discord** и нажмите «Развернуть структуру сервера». Сначала появится план. Бот ничего не удаляет и не трогает чужие роли и каналы. Галочка ставит иконку сервера и аватар бота из эмблемы.

## 5. Проверить на сервере

- Обычный аккаунт видит только ЛОББИ. После кнопки в #добро-пожаловать открываются ОТЕЛЬ и ГОСТИНАЯ.
- `/номера`, `/бронь`, `/мои-брони` отвечают только вам.
- Новая бронь на сайте приходит в #брони от персоны «Ресепшен».
- Смена цены в панели обновляет карточку в #номера.

## Что проверить в текстах

- Правила в #правила написаны как черновик. Замените их на правила вашего проекта в `rulesBoard` (`server/discord/embeds.js`).
- Анкеты сотрудников в #персонал появятся, когда в панели будут настоящие записи. Примеры из сида бот не показывает.

## Отдельные боты

Персоны работают через вебхуки: у каждой своё имя и аватарка, но одно приложение. Отдельный бот в списке участников возможен только как отдельное приложение в Developer Portal.
