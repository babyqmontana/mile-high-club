# Рекламный ролик Mile High Club

Ролик длится 15 секунд, формат 1920×1080, 30 fps. Это моушен‑дизайн в духе продуктовых промо: тёмный фон, один яркий акцент (золото #F7B50A), мягкое свечение и размытие в движении на быстрых сдвигах. Используются шрифты и палитра сайта, а логотип берётся из `public/img/logo.webp`.

Звук: только SFX (клики, свиши, нарастания, удары, глитч, тональный «логотип»). Музыки в ролике нет, её накладывают поверх.

## Сценарий

| Время | Сцена |
|---|---|
| 0–3.1 с | Плашки‑фильтры «Все / Номера / Отдых / Le Ciel / Сигары». Заливка переезжает на «Номера», появляются карточки Делюкс / Сюит / Пентхаус с ценами |
| 3.1–5.2 с | Список: Sky Pool, Night Pool, The Hot Times, Номер 2601. Последняя строка раскрывается в бронь «2 ночи · 2 гостя · $60 000» |
| 5.2–7.0 с | «Абсолютная высота» и золотой бейдж с логотипом |
| 7.0–9.5 с | «Смотри, какие [36/36] номера свободны», счётчик на перекидном табло |
| 9.5–10.8 с | «И бронируй сразу» |
| 10.8–11.85 с | «В реальном времени» с глитчем, затем схлопывание и большой удар |
| 11.85–15 с | Вспышка, точка, логотип, «MILE HIGH CLUB», «Отель над Лос‑Сантосом», «Забронируйте на сайте» |

## Сборка

Нужны Node с Playwright (Chromium), Python 3 с numpy и ffmpeg.

```bash
node promo/render.cjs promo-out                          # 450 кадров PNG + cues.json
python3 promo/sfx.py promo-out/cues.json promo-out/sfx.wav  # звук по тем же таймингам
ffmpeg -framerate 30 -i promo-out/f%04d.png -i promo-out/sfx.wav \
  -c:v libx264 -preset slow -crf 16 -pix_fmt yuv420p -c:a aac -b:a 256k -shortest -movflags +faststart mhc-promo.mp4
```

- Посмотреть один кадр: открыть `promo/ad.html?t=8.4` через любой статический сервер от корня репозитория.
- Посмотреть ролик целиком в реальном времени: открыть `promo/ad.html`.
- Быстро снять кадры для проверки: `node promo/render.cjs out --stills 0.4,5.9,12.6`.

Тексты, тайминги и звуковые события задаются в `promo/ad.html`. Звуковые события перечислены в массиве `CUES`, `sfx.py` читает его из `cues.json`, поэтому при правке анимации звук пересобирается без ручной синхронизации.

Шрифты лежат в `promo/fonts`: Unbounded, Onest и Cormorant Garamond под лицензией SIL OFL, файлы лицензий рядом.

# Ролик «Ностальгия» (вертикальный, 9:16)

Ролик длится 12,9 секунды, формат 1080×1920, 30 fps. Это моушен в духе «ностальгических» роликов: светящиеся пиксельные 3D‑предметы на чёрном фоне, RGB‑расслоение по краям, ореол цвета предмета, строки развёртки и глитч на склейках. Предметы сменяются строго в долю такта.

Каждый предмет относится к реальной услуге отеля:

| Предмет | Подпись |
|---|---|
| звонок ресепшн | «Добро пожаловать» |
| ключ‑карта 2601 | «Номера до пентхауса» |
| ретро‑телефон с подтверждённой бронью | «Бронь на сайте» |
| надувной круг | «Sky Pool · 38 этаж» |
| винил | «Night Pool · 40 этаж» |
| коктейль | «The Hot Times · бар» |
| клош | «Le Ciel · еда в номер» |
| сигара с дымом | «Сигарный клуб» |
| шампанское | «Вечеринки · Neon Night» |
| журнал | «Журнал «Высота»», с настоящей обложкой |
| башня отеля | «Отель над Лос‑Сантосом» |

Финал: жетон с логотипом, «MILE HIGH CLUB», список услуг и кнопка «Забронируй на сайте».

Музыка своя, её синтезирует `nostalgia_audio.py`: лоу‑фай/синтвейв, 83.35 BPM, ля минор, аккорды Am | F | Dm–E | Am. Сторонних треков в ролике нет. Темп совпадает с темпом референса, поэтому любой трек на ~83 BPM ляжет на склейки.

```bash
node promo/render.cjs promo-out/n --page nostalgia.html            # 387 кадров + cues.json (WebGL через SwiftShader)
python3 promo/nostalgia_audio.py promo-out/n/cues.json promo-out/n  # music.wav, sfx.wav, mix.wav
ffmpeg -framerate 30 -i promo-out/n/f%04d.png -i promo-out/n/mix.wav \
  -c:v libx264 -preset slow -crf 17 -pix_fmt yuv420p -c:a aac -b:a 256k -shortest -movflags +faststart mhc-nostalgia.mp4
```

Порядок и длительность кадров задаются массивом `SHOTS` в `nostalgia.html`, длительности указаны в долях такта.

# Ролик v2 (вертикальный 9:16, 20 с)

Стиль первого референса: продуктовое промо с вкладками, списком, раскрытием карточки, кинетической типографикой, глитчем и раскрытием логотипа. Внутри настоящие экраны сайта (`promo/assets/site-*.webp`, снято с демо-сервера с мобильным разрешением), новый верблюд (`brand/emblem.png`) и переливающаяся надпись (`brand/mhc-wordmark.svg`). Все цифры взяты из стартовых данных сайта.

```bash
node promo/render.cjs promo-out/a2 --page ad2.html        # 600 кадров; можно делить --from/--to на несколько процессов
python3 promo/sfx.py promo-out/a2/cues.json promo-out/a2/sfx.wav
ffmpeg -framerate 30 -i promo-out/a2/f%04d.png -i promo-out/a2/sfx.wav -c:v libx264 -crf 17 -pix_fmt yuv420p -c:a aac -b:a 256k -shortest -movflags +faststart mhc-promo-v2.mp4
```
